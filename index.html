Google Cloud Firestore Connection

Connect your free Firebase Firestore database to enable real-time multi-device sync across different student laptops, phones, and teacher computers.

Firebase Configuration

Copy the firebaseConfig object from your Firebase Console (Project Settings → General → Your apps → Web app) and paste it below:

Firebase Setup & Security Rules Guide:

  1. Enable Authentication: In Firebase Console, go to Build → Authentication → Sign-in method. Enable Email/Password and Anonymous.
  2. Create Admin User: In Authentication → Users, click Add user to create your administrator email and password.
  3. Apply Firestore Security Rules: Go to Build → Firestore Database → Rules, paste the contents of firestore.rules, and click Publish.
  4. Grant Admin Verification in Firestore: In Firestore Database → Data, start collection admins, and create a document with Document ID = your admin user's Auth UID (leave fields blank). Client-side write is blocked by rules (allow write: if false;), guaranteeing that only project owners can designate administrators.
  5. Register Web App: In Project Settings (⚙️) → General → Your apps, copy the firebaseConfig values into the box above.
